Milestone escrow — confirmation status and platform fees

Not part of the public site. Humfiverse cannot release a milestone — that requires the artist and the studio to each confirm it from their own wallet (confirmMilestoneAsArtist / confirmMilestoneAsStudio), and the campaigns below only show who's still waiting on whom. The actions here are sending accrued platform fees to their recipient (§2.71) and, from the contract owner's wallet, cancelling a campaign so its contributors can claim refunds (§2.85). See HumfiverseMilestoneEscrow.sol and planning/technical-architecture.md §2.27.

Platform fees

Read from each contract's own counters. Fees accrue inside each contract and leave only through withdrawFees(), which any wallet can send and which pays only the contract's fee recipient.
