Milestone escrow — confirmation status and platform fees

Not part of the public site. Humfiverse cannot release a milestone — that requires the artist and the studio to each confirm it from their own wallet (confirmMilestoneAsArtist / confirmMilestoneAsStudio), and the campaigns below only show who's still waiting on whom. The one action here is sending accrued platform fees to their recipient (§2.71). See HumfiverseMilestoneEscrow.sol and planning/technical-architecture.md §2.27.

Platform fees

Read from each contract's own counters. Fees accrue inside the contract and leave only through withdrawFees(), which any wallet can send and which pays only the contract's fee recipient.
