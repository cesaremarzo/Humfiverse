# Current Status & Disclaimer

## What's actually true today

- Humfiverse is a **working prototype**: a real web app, backed by two independently verified smart contracts on **Ethereum Sepolia — a public test network.**
- Contract addresses change whenever the contracts get redeployed, which has happened more than once as the design improved. Rather than print one here that will go stale, the live app links every listed catalogue directly to its *current* contract and source code on the block explorer — that's the reference to trust, not anything printed in this document.
- Buying or contributing through the app today is a **real, signed blockchain transaction** — your wallet genuinely signs it, and it genuinely shows up on Sepolia's public explorer. What makes this a prototype and not a live product is that **Sepolia ETH has no monetary value.** No real money has changed hands through this system.
- **No legal entity holds any real royalty right yet.** No royalty income has been independently verified. The catalogues visible in the app today were created by real people testing the platform, but don't represent verified real royalty income.
- **No token has been offered, marketed, or sold to any investor**, anywhere, under any exemption. No regulator has reviewed anything in this document.
- **No contract here has been audited by an independent security firm.** They're covered by an internal test suite (71 passing tests as of this writing) — not the same thing as an audit.

## How to check any claim in this document yourself

- Read the contracts' actual behavior directly from their verified source code, linked from the live app.
- Every completed purchase shows its transaction hash and a link straight to that transaction on the block explorer.
- The test suite's current results are public in the project's source repository.

If something here can't be checked this way, that's worth reporting as an inconsistency — not assumed to be true.
